# finance-app-inf

Creator Finance Platform: clickable prototype (creator view).

## Run it
Double-click `index.html`. No install or build step. Uses an internet connection only for the Manrope font.

## What is in it
- Dashboard: received vs to collect vs overdue, month / quarter / year, team payments
- Projects: follow-up and work-submission drafts, invoices, contracts, edit, reopen
- Analytics: delays, project counts, month over month
- Project closing moment (visuals, sound, haptics)

## Notes
- All data is sample data held in memory; a reload resets it. Uploaded files are not saved.
- Single file by design. When the design settles, port it to Next.js + Supabase (see the product brief).
